# Ledgerloom website

One HTML file, no build step.

## Deploy on Vercel
1. Replace the files in your Vercel project's GitHub repo with this folder (or make a new repo).
2. Vercel: Framework preset "Other", build settings blank. Deploy.

## Before going live
- Contact form: make a free form at formspree.io, replace YOUR_FORM_ID in index.html.
- Team titles: fill in the [Title] spots.
- Client forms link in the footer: point it at the real forms page.
- Haley's photo: see the comment above the woven pattern in the story section.
- Domain: Vercel > Project > Settings > Domains > add ledgerloomllc.com and www.ledgerloomllc.com.
- Google Search Console: add the site, submit https://www.ledgerloomllc.com/sitemap.xml
